HOW TO UPDATE ON IPHONE
1. Export and back up existing cases first. Do NOT delete the installed Home Screen app.
2. Unzip the update ZIP in iPhone Files.
3. In GitHub upload all update files to the root of losoonicee/Dispute-pro, replacing same-named files.
   Existing assets not in the update ZIP should be left untouched.
4. Tap Commit changes. Reopen the website online to let it cache the offline model.
5. Open Reader > Upload & read — free first (or Free Knowledge Vault).
6. Compare every OCR field with the actual credit report. Blank means unknown, not zero or an error.

PRIVACY
Never upload the private credit notes package to your PUBLIC GitHub repo. Only import your private notes
inside the Knowledge Vault with a passphrase. The standalone Dispute Desk 2 is an independent local-only
workspace; its saved case is separate from Dispute Studio. It does not automatically sync cases to Studio.
Do not turn on local saving for private client credit reports on a shared device. Local browser storage
is not a substitute for professional encrypted client storage.

LIMITATIONS
The bundled OCR is a separate engine that reads image text, not a large language model. It may misread
numbers or miss small text. Testing in desktop Chromium is not proof of identical iPhone behavior.
PDF.js and OCR engine are included locally; first visit to website requires internet to cache those files.
Optional paid OpenAI integration is unchanged and can be used later after billing is configured.
